# Diabetes Prediction Using Machine Learning

## Project Overview
This project uses machine learning to predict whether a patient has diabetes based on medical attributes.

## Dataset
- Dataset: Pima Indians Diabetes Database
- Source: [Kaggle Dataset](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)
- Total Records: 768
- Features: 8
- Target Variable: Outcome

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
Logistic Regression

## Data Preprocessing
- Handling invalid zero values
- Median imputation
- Feature standardization
- Train-test splitting

## Evaluation Metrics
The model is evaluated using:
1. True Positive (TP)
2. True Negative (TN)
3. False Positive (FP)
4. False Negative (FN)
5. Accuracy
6. Precision
7. Recall
8. F1-Score

## Project Files
- Diabetes_Prediction_Assessment.ipynb: Complete Google Colab notebook.
- confusion_matrix.png: Confusion matrix visualization.
- diabetes_evaluation_results.csv: Evaluation results.
- diabetes_predictions.csv: Actual and predicted values.

## Conclusion
This project demonstrates binary classification using Logistic Regression and evaluates the model using standard classification performance metrics.
